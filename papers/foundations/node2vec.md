# ⭐ node2vec: Scalable Feature Learning for Networks

> ⭐ **필독 (MUST-READ)** · 탑티어 학회 게재: **KDD 2016**

[← 카테고리](index.md) · 원문: [arXiv:1607.00653](https://arxiv.org/abs/1607.00653)

- **저자**: Aditya Grover, Jure Leskovec
- **발표처/연도**: KDD 2016

## 문제 (Problem)
[DeepWalk](deepwalk.md) 의 단순(균일) 랜덤워크는 탐색 전략이 **고정** 되어 있다. 그런데 그래프에는 성격이
다른 **두 가지 유사성** 이 공존한다.
- **동질성(homophily)**: 같은 커뮤니티/클러스터에 속한 노드는 가깝게 임베딩되어야 한다.
- **구조적 동등성(structural equivalence)**: 그래프 내 **역할** 이 비슷한 노드(예: 여러 커뮤니티의 *허브*)는,
  멀리 떨어져 있어도 가깝게 임베딩되어야 한다.

균일 워크는 이 둘 사이를 조절할 수 없어, 한 임베딩이 두 신호를 동시에 잡기 어렵다.

## 방법 (Method)
탐색 편향을 조절하는 **유연한 2차(biased) 랜덤워크** 를 도입한다. 두 하이퍼파라미터로 "다음 스텝"을 제어:
- **복귀 파라미터 p (return)**: 방금 떠나온 노드로 되돌아갈 경향.
- **인아웃 파라미터 q (in-out)**: 출발지 근처에 머물지(**BFS**), 더 멀리 나아갈지(**DFS**) 결정.

생성된 워크에 [DeepWalk](deepwalk.md) 와 동일하게 **SkipGram + 네거티브 샘플링** 을 적용해 임베딩을 학습한다.
즉 **워크 샘플링 전략만 일반화** 한 것이다.

## 핵심 메커니즘 — node2vec이 *실제로* 하는 것

> **한 줄 요약**: 워크를 **2차(직전 노드를 기억하는)** 로 만들어, p·q 로 "지금까지 본 동선과의 거리"에
> 따라 다음 노드를 선택 → **BFS(구조적 동등성)와 DFS(동질성)** 사이를 **연속적으로 보간** 한다.

### 흔한 오해 vs 실제

| | ❌ 오해 | ✅ 실제 |
|---|---|---|
| 워크의 차수 | DeepWalk처럼 **1차 마르코프**(현재 노드만 봄) | **2차(second-order)** — *직전 노드 t* 도 함께 보고 다음을 결정 |
| 2차의 의미 | 시퀀스가 2단계뿐 | **마르코프 차수**가 2일 뿐, 워크는 여전히 **길다**($l$스텝) |
| α_pq 값 | 확률(합=1) | **정규화 안 된 가중치(점수)** — 나중에 합으로 나눠 확률화 |
| BFS가 잡는 것 | 동질성(커뮤니티) | **구조적 동등성(역할)** — 자주 헷갈림 |
| DFS가 잡는 것 | 구조적 동등성 | **동질성(커뮤니티)** |
| DeepWalk와 관계 | 전혀 다른 방법 | **p=q=1 이면 node2vec = DeepWalk** (특수 케이스) |

### ① 2차 편향 랜덤워크 — 워크를 어떻게 만드나

직전에 `t → v` 로 이동해 지금 `v` 에 있다고 하자. 다음 노드 `x` 로 가는 **전이 점수(비정규화)** 는
$\pi_{vx} = \alpha_{pq}(t,x)\cdot w_{vx}$ 이고, 편향 `α` 는 `t` 와 `x` 의 최단거리 `d_{tx} ∈ {0,1,2}` 로 정해진다:

$$
\alpha_{pq}(t,x)=
\begin{cases}
\tfrac{1}{p} & d_{tx}=0 \quad(\text{직전 노드 }t\text{ 로 복귀})\\[2pt]
1 & d_{tx}=1 \quad(t\text{ 와도 인접한 공통 이웃})\\[2pt]
\tfrac{1}{q} & d_{tx}=2 \quad(t\text{ 에서 더 멀어짐)}
\end{cases}
$$

- **"2차"의 뜻**: 다음 노드 선택이 **현재+직전** 노드에 의존 — $P(s_{i+1}\mid s_i, s_{i-1})$
  (1차 DeepWalk는 $P(s_{i+1}\mid s_i)$). 식에 *직전 노드 $t$* 가 등장하는 이유다. 워크 자체는 여전히
  길게 이어진다($s_0\to s_1\to\cdots\to s_l$).
- **점수 → 확률(정규화)**: `α` 는 확률이 아니라 **점수** 다. 이웃 전체 합으로 나눠 확률을 만든다:
  $$P(\text{다음}=x\mid v,t)=\frac{\pi_{vx}}{\sum_{x'\in N(v)}\pi_{vx'}}$$
  그래서 $\tfrac1p + 1 + \tfrac1q$ 가 1을 넘어도 무방하다. (예: $p{=}1,q{=}2$ → 점수 $1,1,0.5$ →
  $Z{=}2.5$ → 확률 $0.4,0.4,0.2$.) $d_{tx}{=}1$ 의 "1"은 **기준값** 이라 $p,q$ 는 상대 배율일 뿐 —
  비율만 의미 있고, $p{=}q{=}1$ 이면 균일 분포가 되어 DeepWalk와 같아진다.
- **p·q 효과**: 작은 $p$ → 자꾸 **복귀**(좁은 지역 촘촘히, **BFS 성향**) · 작은 $q$ → **바깥으로**
  나아감(**DFS 성향**). 이렇게 만든 워크를 길이 $l$·노드당 $r$개·윈도우 $k$ 로 모아 SkipGram 학습.

> ⚠️ **헷갈리기 쉬운 세 값은 모두 별개다**: **워크 길이 $l$**(문장 노드 수) · **마르코프 차수 = 2**(다음
> 선택에 과거 1개를 더 봄) · **SkipGram 윈도우 $k$**(동시 등장으로 볼 ±범위).

### ② BFS ↔ 구조적 동등성 · DFS ↔ 동질성 (왜 작동하나)

- **BFS(국소·반복)**: 직속 이웃을 미시적으로 반복 관찰 → 노드의 **역할/차수 지문** 을 정밀하게 특징화 →
  멀리 떨어진 허브끼리도 지문이 닮음 → **구조적 동등성**.
- **DFS(원거리)**: 커뮤니티를 멀리까지 따라가 같은 클러스터 노드와 자주 동시 등장 → **동질성**.
- 실험(**Figure 3**, Les Misérables)이 이를 확인: **동질성** = `p=1, q=0.5`(DFS 성향), **구조적 동등성**
  = `p=1, q=2`(BFS 성향). p·q 탐색으로 **두 극단 사이 최적점** 을 고른다.

> 📖 **예시 — 레미제라블(인물 공출현망, Figure 3)**: 같은 그래프를 두 가지로 색칠한다.
> - **커뮤니티(동질성)** = *"누구와 어울리나"*: 혁명 학생 그룹(앙졸라스·마리우스·쿠르페락…)처럼 **함께
>   자주 등장** 하는 무리끼리 같은 색.
> - **구조적 역할(구조적 동등성)** = *"어떤 자리인가"*: **장발장**(전체 줄거리의 허브)과 **앙졸라스**(학생
>   그룹의 허브)는 **다른 무리** 지만 둘 다 *"내 무리의 중심"* 이라는 **같은 역할** → 가깝게 묶임.
>   여러 무리를 잇는 *다리*(예: 자베르), 한 인물 곁에만 나오는 *단역(잎)* 도 무리가 달라도 역할이 같으면 묶인다.
>
> 즉 **동질성 = 연결의 *밀집*(누구와 함께)**, **구조적 동등성 = 연결의 *모양/패턴*(어떤 자리)**. 서로 만난
> 적 없어도 역할 모양이 같으면 구조적으로 동등하다.

> ⚠️ **Figure 1의 "함정"**: 논문은 예시 노드로 두 개념을 *정의* 한다 — **s1**(=u 와 같은 커뮤니티 → 동질성),
> **s6**(=u 와 같은 허브 → 구조적 동등성). Figure 1에서 s1은 BFS 이웃, s6은 DFS 도달 노드라 *"BFS=동질성"*
> 처럼 거꾸로 읽히기 쉽지만, **s1·s6은 정의 예시일 뿐 BFS/DFS 매핑이 아니다.** 매핑의 근거는 "전략이
> 전체 노드에 만드는 임베딩 구조"이며, 원문도 *"neighborhoods sampled by **BFS** … **structural
> equivalence**", "**DFS** … **homophilous communities**"* 로 명시한다.
> ([Stanford PDF](https://cs.stanford.edu/~jure/pubs/node2vec-kdd16.pdf) · [arXiv](https://arxiv.org/abs/1607.00653))

### ③ 엣지 임베딩 (링크 예측)
노드 쌍 `(u,v)` 의 엣지 특징은 두 노드 임베딩의 **이항 연산자** 로 만든다: **Hadamard**(원소곱, 보통 최고),
평균, L1(`|f(u)-f(v)|`), L2. 이를 분류기에 넣어 링크 존재를 예측.

### 한 줄 비유
> "지도 없이 무작정 걷기(DeepWalk)" 가 아니라, **"방금 어디서 왔는지 기억하고, 되돌아갈지/더 나아갈지
> 성향(p,q)을 정해 산책"** 하는 것. (단, 산책 자체는 길게 한다.)

## 핵심 기여 (Contributions)
- **2차 편향 랜덤워크(p,q)** 로 DeepWalk를 일반화 — 탐색 편향을 연속적으로 조절.
- 하나의 임베딩으로 **노드 분류와 링크 예측** 을 모두 강하게 수행(엣지용 이항 연산자 제시).

## 무엇을 학습하고 어떻게 평가하나 (전이적, transductive)

> **한 줄 요약**: 학습 결과물은 **노드별 임베딩 표 $Z\in\mathbb{R}^{N\times d}$**(룩업 테이블)이라,
> **그 그래프 한 장의 노드 전용** 이다. 평가도 **같은 그래프** 안에서 **라벨만 가렸다 맞히는** 식이다.

- **학습되는 것 = 출력 그 자체**: 파라미터가 곧 임베딩($Z$의 각 행 = 특정 노드 1개). 새 노드의 임베딩을
  계산하는 *함수* 가 없어, 새 노드/새 그래프엔 **재학습** 이 필요하다(얕은·전이적).
- **평가 절차(다중 라벨 분류)**:
  1. 그래프 **전체**(모든 노드·엣지)로 학습 → 모든 노드 임베딩 확보(라벨 안 씀).
  2. 노드 라벨 중 **일부 비율만 공개**($T_R$=10\%\~90\%)해 분류기(로지스틱 회귀) 학습.
  3. **같은 그래프의 라벨 가린 노드** 예측 → **Micro/Macro-F1**.
- ⚠️ **나누는 건 그래프가 아니라 라벨**: 테스트 노드도 임베딩 학습 때 이미 그래프에 있던 노드다.
  [BlogCatalog](../../datasets/blogcatalog.md)·[PPI](../../datasets/reddit-ppi.md)·Wikipedia 는
  **서로 독립된 단일-그래프 실험 3개** 다(한 그래프에서 배워 다른 그래프로 전이하는 게 아님).
- 대조: 함수(가중치 $W$)를 배우는 [GraphSAGE](graphsage.md)·[GAT](gat.md)는 **귀납적** → 새 그래프 OK.

[BlogCatalog](../../datasets/blogcatalog.md), [PPI](../../datasets/reddit-ppi.md), Wikipedia 의 다중 라벨
